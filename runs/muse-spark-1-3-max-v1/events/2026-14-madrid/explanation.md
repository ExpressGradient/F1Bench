## Track, tyres, strategy, incidents

- **Madring:** Hybrid street/permanent, 5.414 km, 22 corners, 589 m main straight to T1, heavy braking T13/T17 (175→60 mph), La Monumental banked 550 m 24% gradient, blind/gradient/high-load, little margin. First F1 new track since Vegas 2023. Top speed 340 kph. Only 2 Straight Mode zones (start/finish, T3-T4). Overtake Mode (electrical boost) replaces DRS. Designed T1/T13/T17 passes, but consensus: overtaking genuinely hard, track position crucial, Monaco/Hungary-like, strategy offset needed.
- **Precedent chaos:** F3 test 19 red flags, F2 fiery crash red flag, F1 FP2 LIN crash, FP3 HAM+BEA crashes (2 reds), ALB wall, SAI near-miss. Drivers (SAI) predict safety cars/red flags/yellows; barrier repair = red flag (as Monza). Qualifying calm (no reds) shows drivers can survive, but 57-lap race + heat + deg + first-ever start = high incident rate. Estimated ≥1 SC ~75%, red flag ~20-25%.
- **Tyres:** Pirelli C2 Hard/C3 Medium/C4 Soft all raceable. New smooth asphalt, high grip, warm-up tricky (1 lap), graining. Deg Wolff: 0.8s/lap FP1 (six stops joke → thinks 1-stop), 0.3s/lap FP2 long runs → points to 2-stop. Laps 18-24 first window. ## Calibration and risks

- Main uncertainty: McLaren true race pace (no NOR long-run, graining) — if McLaren = Mercedes, NOR win → 40%+, ANT → 33%; if graining persists, NOR → 30%, VER/HAM up.
- RUS setup revert: if FP1 pace returns, RUS win → 7-8%; if tyre temps persist, → 3-4%.
- Ferrari race-sim 0.9s gap likely overstated (traffic, 2-lap sample) — used 0.30/0.36, not 0.90. If true 0.6s, HAM/LEC wins halve.
- SC/red lottery fat tails under-modeled by Gaussian — midfield win/pod understated vs true chaos (F3 19 reds). LAW/LIN/COL wins 0.0002-0.03% may be 2-3x low if early red bunches + leaders collide. T1 3.5% + midfield 10% partly captures.
- DNF 4.4 may be low for 32°C new street circuit + 2026 PU fragility — Zandvoort 6. If 5-6, backmarker points double, top wins compress 1-2% each.
- 0.0 wins for HUL/OCO/GAS/TSU/BEA/ALB+ in 600k are sampling zeros (true ~1e-6 to 1e-5), negligible for Brier, conservative for log-loss — floor would violate occupancy 1.0.
